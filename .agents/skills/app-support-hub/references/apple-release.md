# Apple Release Reference

Last reviewed: 2026-08-25.

## Required checks

- Support URL is publicly reachable, app-specific, localized when used, and provides a real contact path.
- Privacy Policy URL is publicly reachable and matches the uploaded build.
- App Privacy answers include third-party partner behavior and remain current.
- Final URLs are recorded in the app repository's metadata source.

## Current contact risk

Apple's App Store Connect reference currently says the required Support URL must lead to actual contact information, listing legal address, email, and telephone as examples where local law may require them. This repository currently offers public GitHub Issues only. Treat that as an explicit owner-approved risk, not confirmed compliance.

If rejected, add a dedicated public support email or private form and update the site, policies, Issue instructions, operations docs, and App Store fields together. Do not expose the private App Review contact by default.
