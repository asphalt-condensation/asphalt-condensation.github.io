# Workflow Map

## App onboarding

Read:

- `docs/ADD_AN_APP.md`
- `docs/CONTENT_MODEL.md`
- `docs/LOCALIZATION.md`
- `docs/PRIVACY_CHANGE_CHECKLIST.md`

Touch as needed:

- manifest, localized Markdown, owned icon;
- Issue Forms and labels;
- app context file and browser tests.

## Support or troubleshooting copy

Read:

- `docs/SUPPORT_OPERATIONS.md`
- `docs/apps/<slug>.md`
- all support locales for the app.

Check privacy links, public-channel warnings, diagnostic fields, and destructive actions.

## Privacy policy

Read:

- `docs/PRIVACY_CHANGE_CHECKLIST.md`
- `docs/APP_STORE_CONNECT.md`
- app source evidence and `docs/apps/<slug>.md`.

Update every locale and external disclosure source when meaning changes.

## UI or component change

Read:

- `docs/DESIGN_SYSTEM.md`
- `ARCHITECTURE.md` for shared rendering changes.

Run axe and overflow tests, then inspect desktop/mobile screenshots.

## Release or rollback

Read:

- `docs/DEPLOYMENT.md`
- `docs/REPOSITORY_SETTINGS.md`
- `docs/APP_STORE_CONNECT.md` for store-bound URLs.

Verify live Pages, Issues, security reporting, and repository Actions instead of assuming settings match the documentation.
