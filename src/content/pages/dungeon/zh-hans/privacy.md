《地牢》是一款离线单人游戏。本政策说明 App 如何处理信息。

## 数据收集

《地牢》不会收集、传输、出售或共享个人数据。App 不包含用户账户、广告、数据分析、追踪技术或第三方数据收集 SDK。

## 设备本地数据

《地牢》只会在设备本地保存玩家选择的语言和游戏内死亡次数，用于保留游戏偏好及相关显示。这些信息不会离开设备，删除 App 即可一并移除。

## 网络访问

《地牢》不需要网络连接，也不会向服务器发送游戏过程或设备信息。

本支持网站由 GitHub Pages 托管。访问本网站或提交 GitHub Issue 与使用《地牢》App 是相互独立的行为，并受 GitHub 自身隐私规则约束。

## 儿童隐私

《地牢》是一款心理恐怖游戏，并非面向年幼儿童。App 不会有意收集儿童或其他用户的个人信息。

## 政策变更

如果《地牢》的数据处理方式发生变化，我们会在相关版本发布前更新本政策和 App Store 隐私披露。页面顶部的生效日期和最近更新日期用于标识当前政策版本。

## 问题与联系

如有一般隐私问题，请使用[公开支持请求表单](https://github.com/asphalt-condensation/asphalt-condensation.github.io/issues/new/choose)。GitHub Issue 为公开内容，并且需要 GitHub 账号。请勿填写隐私或敏感信息。

如需报告本网站仓库的安全漏洞，请使用 [GitHub 私密安全报告](https://github.com/asphalt-condensation/asphalt-condensation.github.io/security/advisories/new)，不要提交公开 Issue。
