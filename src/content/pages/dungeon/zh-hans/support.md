《地牢》是一款适用于 iPhone 和 iPad 的离线横屏心理恐怖游戏。

> 支持请求通过公开的 GitHub Issue 处理，提交时需要 GitHub 账号。请勿填写真实姓名、邮箱地址、设备标识符、含有个人信息的截图或其他敏感信息。

## 推荐设置

- 建议佩戴耳机，以获得完整的方向性声音体验。
- 开始关卡前，请确认设备音量可以正常听见。
- 请将设备旋转至任一横屏方向。
- 为确保声音稳定，请断开当前不使用的蓝牙音频设备。

## 操作方式

- 在左下区域按住并拖动以移动。
- 轻触右下区域以暂时关灯。
- 使用手形按钮打开宝箱或使用出口。
- 使用书本按钮查看已经找回的记忆。
- 轻触菜单和剧情画面继续。

## 常见问题

### 听不到游戏声音

请提高系统音量，断开并非当前使用的蓝牙音频设备，然后重新尝试耳机或设备扬声器。如果游戏曾被电话或其他音频 App 中断，请返回《地牢》并继续游戏。

### 游戏画面无法旋转

《地牢》仅支持横屏。请关闭设备的方向锁定，然后将设备旋转至任一横屏方向。

### 操作没有按预期响应

请确认触摸位置位于教程中显示的有效操作区域。需要切换移动与其他操作时，请先抬起手指。如果问题持续出现，请关闭并重新打开 App。

### 如何重置本地偏好？

删除并重新安装《地牢》即可重置所选语言和本地保存的死亡次数。此操作无法撤销。
