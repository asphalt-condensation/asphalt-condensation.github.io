**Effective date:** August 24, 2026

**Last updated:** August 25, 2026

Dungeon is an offline, single-player game. This policy explains how the app handles information.

## Data collection

Dungeon does not collect, transmit, sell, or share personal data. The app does not include user accounts, advertising, analytics, tracking technologies, or third-party data-collection SDKs.

## Data stored on the device

Dungeon stores the player's selected language and in-game death count locally on the device. This information is used only to preserve game preferences and progress-related presentation. It is not transmitted off the device and can be removed by deleting the app.

## Network access

Dungeon does not require an internet connection and does not send gameplay or device information to a server.

The support website is hosted by GitHub Pages. Visiting this website or opening a GitHub Issue is separate from using the Dungeon app and is subject to GitHub's own privacy practices.

## Children's privacy

Dungeon is a psychological horror game and is not directed to young children. The app does not knowingly collect personal information from children or any other users.

## Changes to this policy

If Dungeon's data practices change, this policy and the App Store privacy disclosure will be updated before the changed version is released. The effective date and last-updated date above identify the current policy version.

## Questions

For a general privacy question, use the [public support request form](https://github.com/asphalt-condensation/asphalt-condensation.github.io/issues/new/choose). GitHub Issues are public and require a GitHub account. Do not include private or sensitive information.

For a security vulnerability in this website repository, use [GitHub's private security advisory form](https://github.com/asphalt-condensation/asphalt-condensation.github.io/security/advisories/new) instead of a public issue.
